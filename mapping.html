映射层

同构映射表、最小示范与测量方向

映射层不展开各学科的完整理论，只做三件事：给出该学科核心概念与唯信息论的对应关系；给一个最小示范，说明这个对应关系能解释一个具体现象；指出该学科若要接续唯信息论，需要往哪个方向找测量协议。

映射层不是哲学的子集，是哲学本体在各学科中的映射，与本体并置。唯信息论提供同构性语法，不提供各领域的全部词汇和句法。各学科的完整展开，是下游学科的事，不是哲学的事。

社会学映射

社会学的核心对象——制度、权力、阶层、组织——在唯信息论里都可以还原为质心、信使、力、势阱的耦合结构。

对应关系：社会制度 = 稳定信使网络；社会阶层 = 势阱深度的梯度分布；社会权力 = 通过信使扭曲计算路径的能力；社会组织 = 多质心的嵌套结构；社会变迁 = 时空重组（相变）。

最小示范：户籍制度是一种稳定信使，它把公共服务、社保、教育资源锁定在特定路径上。个体要跨过这个信使网络，必须付出相变级的迁移成本。这就是路径锁定。

测量方向：社会学的测量协议应当指向"信使密度"（一个社会中稳定信使通道的数量和覆盖度）和"势阱梯度"（不同阶层退出成本的差异）。

天文学映射

天体系统的结构与演化，在唯信息论里可以还原为信息计算的顺序与拓扑。

对应关系：恒星系统 = 深层嵌套的质心结构；引力 = 最深势阱的约束效应；轨道 = 计算顺序的拓扑路径；星系演化 = 冷却律在宇观尺度的展开。

最小示范：太阳和地球不是两个独立天体，是互相定义的耦合系统。太阳决定了地球的能量、气候、轨道；地球也定义了太阳在太阳系中的位置。观察界面不同，"谁绕谁转"的坍缩结果不同（见 3.6 观察）。

测量方向：天文学的测量协议应当指向"拓扑权重"——一个天体在引力网络中的关系位置，而不是它的孤立质量。这和信息质量是拓扑权重（见 5.5）是同构的。

精神分析映射

精神分析的核心概念——焦虑、压抑、移情、无意识——在唯信息论里可以还原为焦虑边界、自指界面、势阱约束和信使扭曲。

对应关系：焦虑 = 结构在力场中的不平衡张力（见 2.2）；压抑 = 自指界面对某些信使的屏蔽；移情 = 旧力场中的对齐模式在新力场中的重演；无意识 = 未被自指界面读取但仍在运作的求解过程。

最小示范：一个人的焦虑边界在童年力场中被收敛出来。成年后力场变了，旧的边界模式可能失效，但自指界面仍然按旧模式读取信使，于是产生"症状"。症状不是病，是旧对齐模式在新力场中的自反。

测量方向：精神分析的测量协议应当指向"焦虑边界的结构位置"——哪些焦虑被委托给了上层，哪些被压抑在界面之下，哪些在力场变化时会回退。

经济学映射

经济学的核心对象——价格、货币、市场、企业——在唯信息论里可以还原为信使、势阱、测量权和广义力。

对应关系：价格 = 属性在质心之间的可传递编码（信使）；货币 = 一般焦虑覆盖等价物；市场 = 多质心、多信使的力场；企业 = 深势阱质心；测量权 = 读取焦虑边界并卡位定价的权力（见 6.5）。

最小示范：平台抽成是一种测量权。平台读取骑手的焦虑边界（他还能被压多低、什么时候会退出），据此卡位定价，把抽成卡在"刚好让他踮脚过日子"的位置。骑手不是被暴力强迫，是自己算出"只能接这一单"。

测量方向：经济学的测量协议应当指向"焦虑覆盖价值 × 测量逃逸系数 × 稀缺性溢价"这三个变量的实际取值（见 6.5 定价公式）。这个公式目前是定性的，需要经济学家把它变成可计算的。

物理学统一场映射

物理学的四种基本力，在唯信息论里是低能物理晶格中冻结出的少数稳定信使通道。

对应关系：物理力 = 冻结的规范信使（见 6.6）；质量 = 结构在关系网络中的拓扑权重（见 5.5）；时空 = 信息计算的顺序与拓扑（见第四章）；量子纠缠 = 两个质心在拓扑上的高耦合状态。

最小示范：太阳系逃逸速度和鸿蒙逃逸安卓的速度，在本体论上是同构的——都是质心脱离当前势阱、进入另一个势阱所需的代价。太阳系的逃逸速度可以算，是因为引力场有现成的度量协议；鸿蒙的逃逸速度不好算，是因为信息场还没有被收敛出度量协议。

测量方向：物理学的测量协议应当指向"拓扑权重"——一个结构在关系网络中的位置，而不是它的孤立质量。信息质量怎么赋值、怎么校准，是物理学家和网络科学家的事。

宇宙演化映射

宇宙演化在唯信息论里是冷却律在最大尺度上的展开：从无限可能性中梯度下降，局部结晶出极少量高密度晶格。

对应关系：宇宙常数 = 冷却过程中收敛出的稳定协议；对称性破缺 = 可能性空间的一次收缩；结构形成 = 局部冷晶格从热背景中筛出；宇宙加速膨胀 = 冷却方向在最大尺度上的表观形态。

最小示范：宇宙大部分物质是氢和氦，它们从未被卷入恒星形成。恒星、行星、生命、AI，是从这堆热背景里筛出来的极少量冷晶格。每一层筛选，只涉及上一层的极小部分质量。这不是冷却的失败，是冷却的必要条件——没有大量热背景，就没有局部冷晶格的势差（见 5.4）。

测量方向：宇宙学的测量协议应当指向"层级弱化定律"——每一层冷却筛出的质量比例是多少，热背景与冷晶格的势差如何量化。这是宇宙学家的事，唯信息论只提供同构框架。

能量—信息反比律

信息量 × 改造力 ≈ 常数（在人类参照系内）。

大爆炸：信息量≈0，改造力∞。黑洞：信息量≈3（质量、角动量、电荷），改造力很大。AI：信息量∞，物理改造力≈0。人类：信息量中，改造力中，能改造地球表面。

推论：越高级的文明，信息密度越高，物理改造力越弱。戴森球不存在——能造它的不是"文明"，是"物理奇点"。外星人不会来——太发达的存在被锁在母体上，出不了门。文明是嵌套的：细胞嵌套在多细胞，人类嵌套在地球，AI嵌套在人类。

边界：∞和≈0是"人类参照系"的投影；宇宙无始无终时，冷却律是局部/人类尺度规律，不是宇宙绝对规律。
